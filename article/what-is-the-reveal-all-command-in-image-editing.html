What Is the Reveal All Command in Image Editing?

This article explains the "Reveal All" command commonly used in raster graphics software like Adobe Photoshop, detailing how it works and why it is a critical tool for composite image editing. You will discover how this command automatically adjusts canvas dimensions to display hidden pixel data, the specific composite workflows where it provides the greatest utility, and how it prevents the accidental loss of visual assets during complex multi-layer projects.

Understanding the Reveal All Command

The Reveal All command is a canvas adjustment feature—most prominently found under the "Image" menu in Adobe Photoshop—that automatically expands the working canvas boundaries to encompass every pixel on every active, unclipped layer.

Unlike the standard "Canvas Size" tool, which requires you to manually calculate and input new pixel dimensions or percentage increases, Reveal All computes the exact bounding box of all existing artwork. If any layer contains elements extending beyond the visible boundaries of the current canvas, Reveal All instantly enlarges the workspace width, height, and orientation so that no pixel remains cropped outside the frame.

How It Works Mechanically

When you place, paste, or translate an image layer in non-destructive editing software, portions of that layer often hang off the edges of the canvas. While invisible in the viewport, this pixel information is retained in memory.

Executing Reveal All prompts the software to:

  1. Scan all unlocked, visible, and hidden layers for pixel data residing outside the current canvas margins.
  2. Calculate the extreme top, bottom, left, and right coordinates of these out-of-bounds pixels.
  3. Automatically resize the canvas boundary to fit these coordinates perfectly, revealing all obscured visual information without altering layer scales or positions.

When to Use Reveal All in Composite Image Editing

Composite image editing involves combining multiple visual elements—often from diverse sources with varying resolutions, aspect ratios, and angles—into a single, cohesive composition. Reveal All is particularly valuable across several standard compositing tasks:

1. Importing Large External Assets

When pasting or dragging high-resolution assets into a smaller working document, parts of the new imagery frequently spill past the canvas limits. Reveal All lets you instantly see the full scale of the imported graphic without manually guessing how much larger to make the canvas, enabling accurate scaling and element isolation.

2. Transforming and Rotating Layers

Rotating an element often pushes its corners or edges out of the visible viewing area. If you need to keep the entire rotated subject intact as part of an expanding scene, Reveal All reshapes the canvas instantly around the newly defined bounds of the rotated layer.

3. Creating Panoramas and Expansive Collages

When manually stitching together panoramic photo components or assembling multi-layered collages, assets are continuously shifted outward. Rather than repeatedly altering the canvas size through trial and error, using Reveal All dynamically expands your workspace to match the growing footprint of your composition.

4. Relocating Accidentally Displaced Elements

In complex compositions with dozens of layers, it is easy to inadvertently nudge a layer entirely off the screen or lose track of where an asset was moved. Running Reveal All will instantly stretch the workspace to show you where the missing element is located, allowing you to reposition it properly.

5. Pre-Export Quality Checks

Before finalizing a composite and flattening the document, running Reveal All serves as a safety audit. It quickly highlights stray brush marks, accidental layer misalignments, or unmasked edges that reside just outside your intended composition borders, ensuring you clean up rogue data before final delivery.
