How to Rotate an Image 90 Degrees Clockwise

Rotating an image exactly 90 degrees clockwise is a fundamental editing step used to correct orientation issues caused by camera sensors or scanning errors. This guide outlines direct, step-by-step methods to apply an exact 90-degree clockwise rotation across common operating systems, mobile devices, and professional photo editing software without distorting the picture.

Windows (Photos and Paint)

  1. Using Windows Photos: Double-click the image to open it in the default Photos viewer. Click the Rotate icon at the top of the window (or press Ctrl + R). Each click turns the image exactly 90 degrees clockwise. Save the file by pressing Ctrl + S.
  2. Using Microsoft Paint: Right-click the image, choose Open with, and select Paint. In the Home tab, locate the Image section, click Rotate, and choose Rotate right 90°. Press Ctrl + S to save.

macOS (Preview and Finder)

  1. Using Quick Actions (Finder): Locate the image file in Finder. Select it and press the Spacebar for Quick Look, then click the Rotate button. Alternatively, right-click the file, go to Quick Actions, and select Rotate Right. Each action performs an exact 90-degree clockwise rotation.
  2. Using Preview: Double-click the image to open it in Preview. Go to the top menu and select Tools > Rotate Right, or simply press Command + R.

Adobe Photoshop

  1. Open your image in Photoshop.
  2. In the top navigation bar, click on the Image menu.
  3. Hover over Image Rotation.
  4. Select 90° Clockwise (or 90° CW). This applies the rotation to the entire canvas and all layers within the project.
  5. Save your changes via File > Save.

GIMP

  1. Open the image in GIMP.
  2. Click on the Image menu at the top.
  3. Hover over Transform.
  4. Select Rotate 90° clockwise.
  5. Export or overwrite the file via File > Overwrite [filename] or File > Export As.

Mobile Devices (iOS and Android)

  1. Apple iOS (Photos app): Open the photo, tap Edit in the top-right corner, select the Crop/Rotate icon at the bottom, and tap the square Rotate button in the top-left corner until the image turns 90 degrees clockwise. Tap Done.
  2. Android (Google Photos): Open the image, tap Edit, navigate to the Crop tab, and tap the Rotate icon repeatedly until the image moves 90 degrees clockwise into the desired orientation. Tap Save copy.
