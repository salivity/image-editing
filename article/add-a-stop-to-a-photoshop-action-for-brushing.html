Add a Stop to a Photoshop Action for Brushing

Photoshop actions can dramatically speed up editing workflows, but tasks like selective retouching, dodging, and burning often require custom brushwork. By inserting a "Stop" command into an action, you can pause automated playback, display custom on-screen instructions, and allow the user to manually paint with a brush before resuming the remaining automated steps.

Step 1: Open the Actions Panel

Navigate to Window > Actions or press Alt + F9 (Windows) / Option + F9 (Mac) to open the Actions panel. Locate and expand the specific action you want to modify.

Step 2: Set the Active Tool (Optional but Recommended)

If your manual step requires a specific brush, select the step in the action right before where the pause should occur. Select the Brush tool (B) from your toolbar, configure the desired blend mode, opacity, and hardness, and record the tool selection if necessary so the correct brush settings are active when the action pauses.

Step 3: Insert the Stop Command

  1. In the Actions panel, click on the step immediately preceding where you want the manual intervention to happen.
  2. Click the panel menu icon (the four horizontal lines in the top-right corner of the Actions panel).
  3. Select Insert Stop... from the dropdown menu.

Step 4: Configure the Stop Parameters

A dialog box will appear with two main options:

  • Message: Type clear instructions for the user (e.g., "Select a soft white brush and paint over the subject's eyes. Press Play on the Actions panel when finished to continue.").
  • Allow Continue: Check this box if you want the dialog window to display a "Continue" button alongside the "Stop" button. If left unchecked, the user must explicitly click "Stop," perform the brush strokes, and manually press the "Play" button on the Actions panel to resume. Leaving it unchecked is generally recommended for manual brushing tasks to prevent users from accidentally skipping the brushwork.

Click OK to insert the stop.

Step 5: Test the Action

Run the action from the beginning to ensure the workflow functions as expected. When playback reaches the inserted stop, your message will appear, and the execution will halt. Paint on your layer or layer mask as needed, then click the Play button at the bottom of the Actions panel to finish running the remaining steps.
