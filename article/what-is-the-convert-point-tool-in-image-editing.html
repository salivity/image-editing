What Is the Convert Point Tool in Image Editing?

The Convert Point Tool is an essential vector editing feature used to modify the behavior of anchor points along a vector path. By switching points between sharp corners and smooth curves, this tool provides the control necessary to fine-tune paths, masks, and vector shapes. This guide explains the core purpose of the Convert Point Tool, how it manipulates path direction handles, and why it is indispensable for achieving precise outlines in image editing software.

The Primary Purpose of the Tool

When drawing vector paths with the standard Pen Tool, anchor points naturally fall into two categories: corner points, which create sharp angles, and smooth points, which generate continuous curves. The Convert Point Tool exists to change an anchor point from one type to another after it has already been placed. This eliminates the need to delete and redraw paths when design adjustments are required.

Key Functions and Behaviors

The tool alters path geometry through three primary interactions:

  • Converting Curves to Corners: Clicking directly on an existing smooth anchor point removes its directional bezier handles. This instantly converts the smooth point into a hard corner point, snapping the adjoining segments into straight lines.
  • Converting Corners to Curves: Clicking and dragging outward from a sharp corner point generates new bezier handles. This introduces curvature to the adjacent path segments, transforming the sharp angle into a continuous curve.
  • Splitting Direction Handles (Creating Cusps): By default, smooth points have paired handles that move in tandem to maintain a balanced curve. Clicking and dragging a single handle with the Convert Point Tool breaks this symmetry. This allows editors to adjust the angle and length of a curve entering a point independently of the curve exiting it, creating sharp transitions between curved segments.

Why the Tool Is Essential

Vector paths are frequently used for precision tasks such as creating clipping masks, outlining complex objects, and designing typography or logos. Manually placing anchor points rarely produces a perfect result on the first attempt. The Convert Point Tool gives editors non-destructive control over path geometry, ensuring paths hug contours accurately without introducing unnecessary anchor points that could distort the final graphic.

Workflow Integration

In most graphic design and image editing software, the Convert Point Tool can be accessed directly from the toolbar nested beneath the primary Pen Tool. Additionally, it can be activated temporarily by holding the Alt key (Windows) or Option key (macOS) while using the standard Pen Tool, enabling seamless toggling between drawing paths and adjusting anchor points.
