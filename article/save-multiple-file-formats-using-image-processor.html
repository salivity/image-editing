Save Multiple File Formats Using Image Processor

Using the Image Processor script in Adobe Photoshop is the fastest way to export a batch of images into multiple file formats simultaneously. Instead of manually converting and saving files one by one, this built-in utility lets you select a source folder and output images into JPEG, PSD, and TIFF formats in a single automated pass, complete with custom sizing, color profile conversions, and action integration.

Step 1: Open the Image Processor

  1. Launch Adobe Photoshop.
  2. Navigate to File > Scripts > Image Processor.
  3. Alternatively, you can select files in Adobe Bridge and go to Tools > Photoshop > Image Processor.

Step 2: Select the Source Images

In the Image Processor dialogue window, locate Section 1:

  • Select Use Open Images if your files are already loaded in Photoshop.
  • Select Select Folder to process an entire directory of images, with the optional choice to check Include All Sub-folders.

Step 3: Choose the Destination Location

In Section 2, determine where the exported assets will be saved:

  • Choose Save in Same Location to create output folders alongside your original files.
  • Choose Select Folder to specify a dedicated export directory.

Step 4: Configure Simultaneous File Types

Section 3 controls the output formats. You can enable one, two, or all three available formats at the same time:

  • Save as JPEG: Check this box to export compressed web or preview copies. Set your preferred quality slider (0–12), check Convert Profile to sRGB for standard web color accuracy, and optionally enter dimensions under Resize to Fit to scale the images proportionally.
  • Save as PSD: Check this box to export layered or master Photoshop files. Enable Maximize Compatibility to ensure other Adobe applications can read the files, and specify resize parameters if needed.
  • Save as TIFF: Check this box to export high-quality, uncompressed files suitable for print. Select an option from the Compression dropdown (such as LZW or ZIP) to reduce file sizes without quality loss, and apply resize parameters if necessary.

When multiple formats are checked, Photoshop creates separate subfolders named "JPEG," "PSD," and "TIFF" within your chosen destination directory, keeping your assets organized automatically.

Step 5: Apply Optional Preferences and Run

In Section 4, you can check Run Action if you need to apply a pre-recorded sequence (such as sharpening, watermarking, or color grading) prior to saving. You can also embed copyright metadata directly into the files.

Once your configurations are set, click Run in the top right corner. The script will process the queue and generate each designated file format without requiring further input.
