How to Add Multiple Strokes to a Single Layer

Applying multiple strokes to a single layer allows designers to create complex borders, retro text effects, and dimensional graphic elements without duplicating layers. Modern design and image editing software—such as Adobe Photoshop, Figma, and Affinity Photo—includes native features to stack multiple stroke effects directly onto a single vector or raster element. This guide covers the exact methods used to apply, arrange, and manage multiple strokes within these major editing environments.

Adding Multiple Strokes in Adobe Photoshop

In Adobe Photoshop, multiple strokes are applied using the Layer Styles dialog:

  1. Open Layer Styles: Double-click the target layer in the Layers panel, or click the fx button at the bottom of the panel and select Stroke.
  2. Add a Second Stroke: Look at the left-hand effects list. Next to the Stroke label, click the + (plus) icon. Photoshop will generate a secondary stroke layer style.
  3. Configure the Attributes: Adjust the size, fill type, color, and opacity for each stroke individually.
  4. Manage the Stacking Order: Use the up and down arrow icons at the bottom of the effects list to rearrange the stroke priority. For standard border stacking, set the outer strokes to Position: Outside and make them wider than the inner strokes, or position the primary stroke as Inside and the secondary stroke as Outside.

Adding Multiple Strokes in Figma

Figma supports an unlimited number of strokes per layer by default through its properties panel:

  1. Select the Layer: Click on the frame, shape, or text layer you want to style.
  2. Add Strokes: In the right-hand sidebar, locate the Stroke section and click the + (plus) icon to add the first stroke. Click the + icon again to create additional strokes.
  3. Set Stroke Rules: Set each stroke's color, blend mode, and width.
  4. Order and Alignment: Click and drag individual stroke fields to reorder how they layer over each other. Choose between Center, Inside, or Outside alignment to ensure smaller strokes are not hidden beneath thicker ones.

Adding Multiple Strokes in Affinity Photo and Designer

Affinity handles multi-stroke rendering through dedicated panels:

  1. Using the Appearance Panel (Designer Persona): Select your vector layer, open the Appearance panel, and click the Add Stroke button located at the top. You can stack as many strokes as needed, independently setting widths, colors, and pressure profiles.
  2. Using the Layer Effects Panel (Photo): Open the Quick FX panel, check Outline, set your parameters, and then group the layer with itself or use the fx dialog’s multiple effect instances to stack borders consecutively.

Best Practices for Stacking Strokes

  • Width Hierarchy: When aligning all strokes to Outside, make sure the stroke at the bottom of the effects stack has the highest pixel width, with each subsequent stroke above it decreasing in size.
  • Alignment Strategy: Combine alignment types—placing one stroke to the Inside and another to the Outside—to prevent color overlap issues on sharp corners.
  • Non-Destructive Styling: Save your multi-stroke configurations as layer styles, components, or graphic presets to easily reuse the styling across other elements in your project.
