How to Use the Content-Aware Move Tool in Photoshop

The Content-Aware Move Tool allows image editors to select an object, reposition it elsewhere in the composition, and have the software automatically fill the original location while seamlessly blending the object into its new surroundings. This guide provides a straightforward, step-by-step walkthrough of how to set up the tool, adjust blending settings, and flawlessly move elements within an image without leaving unnatural artifacts.

1. Select the Content-Aware Move Tool

Open your image in Photoshop. Locate the Spot Healing Brush Tool group in the Tools panel (keyboard shortcut: J), click and hold the icon, and select the Content-Aware Move Tool from the flyout menu.

2. Configure the Tool Options

Before making your selection, adjust the key settings in the options bar at the top of the workspace:

  • Mode: Set this to Move to relocate the element (selecting Extend duplicates and blends the object instead).
  • Structure: Set a value between 1 and 7. Higher numbers enforce strict adherence to existing image patterns, while lower numbers allow more flexibility for loose or organic backgrounds.
  • Color: Set a value between 0 and 10 to control how aggressively the software matches the color and tone of the target area.
  • Sample All Layers: Check this if you are working on a separate, blank layer to maintain a non-destructive workflow.

3. Draw a Selection Around the Object

Click and drag around the element you wish to relocate, treating the cursor like a lasso tool. Include a small border of the surrounding background in your selection; this provides the software with the contextual data needed to blend the edges naturally into the new location.

4. Drag the Element to Its New Position

Click inside the selection boundary and drag the object to the desired area in your image. Transform handles will appear around the object, allowing you to scale, rotate, or flip the element to match the perspective and lighting of the new location.

5. Commit and Blend

Press Enter (Windows) or Return (macOS), or click the checkmark in the options bar. Photoshop will simultaneously clear the original area, fill the void using surrounding textures, and blend the edges and lighting of the object into its new placement.

6. Refine the Results

If the initial blend is not seamless:

  • Adjust the Structure and Color values in the options bar while the selection is still active to recalculate the blend automatically.
  • Once satisfied, press Ctrl + D (Windows) or Cmd + D (macOS) to deselect the object.
  • Use the Clone Stamp Tool or Healing Brush Tool to clean up any minor repetitive patterns or edge mismatches left behind.
