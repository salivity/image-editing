Color Burn vs Linear Burn Blending Modes Explained

Both Color Burn and Linear Burn are darkening blending modes used in image editing software like Adobe Photoshop, yet they produce distinctly different visual results on an image. While both modes darken the underlying base image using the tonal information of the blend layer, Color Burn dramatically increases midtone contrast and color saturation, whereas Linear Burn reduces overall brightness linearly with less saturation shift. Understanding the mathematical and visual differences between these two tools enables editors to apply shading, textures, and composite effects with precision.

The Mathematical Difference

The distinction between these two blend modes comes down to the underlying math used to combine pixel values:

  • Color Burn: Calculates the inverse of the base layer, divides it by the blend layer, and inverts the result (1 - (1 - Base) / Blend). Because this operation scales pixel values exponentially, it relies heavily on contrast. Highlights remain relatively protected, while midtones and shadows compress rapidly into saturated, high-contrast tones.
  • Linear Burn: Adds the values of the base and blend layers together and subtracts white (Base + Blend - 1). This is a simple linear reduction of brightness. It treats every tonal value equally, resulting in an even darkening across highlights, midtones, and shadows without creating localized contrast spikes.

Visual Characteristics

The difference in their formulas produces clear visual contrasts:

  • Saturation: Color Burn introduces intense color saturation, especially in midtone areas. Linear Burn darkens pixels with significantly less saturation boost, making colors look more subdued or muddy if applied heavily.
  • Contrast: Color Burn creates a high-contrast, stylized look reminiscent of traditional darkroom burning techniques. Linear Burn provides low-to-medium contrast, pushing pixels into pure black much faster across all color channels.
  • Highlight Retention: Color Burn blends with white by leaving the base image unchanged; blending with colors other than white protects extreme highlights longer before clipping. Linear Burn aggressively pulls highlights down, reducing overall exposure quickly.

The "Special 8" Fill Opacity Behavior

Both Color Burn and Linear Burn belong to Photoshop’s "Special 8" blending modes. Unlike standard blend modes where lowering the Layer Opacity produces an identical result to lowering the Fill Opacity, these two modes respond uniquely to Fill Opacity.

Reducing the Fill slider instead of the standard Opacity slider softens the harsh clipping and extreme contrast transitions of Color Burn and Linear Burn. This allows you to retain the distinctive color interaction and shadow density of each mode while avoiding blown-out blacks or overly saturated artifacts.

When to Use Each Mode

Choose Color Burn when you need punchy, vivid darkening effects. It is ideal for applying grunge textures, enhancing dramatic lighting, adding rich cross-processing effects, or creating stylized shadows where colors need to stay vibrant rather than turn dull.

Choose Linear Burn when you need a uniform, exposure-like reduction in brightness. It works best for creating deep, realistic cast shadows, burning in light leaks, compositing dark texture maps, or merging multi-pass 3D render elements where physical light addition and subtraction are required.
