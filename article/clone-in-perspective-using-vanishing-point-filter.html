Clone in Perspective Using Vanishing Point Filter

The Vanishing Point filter is an essential image editing tool designed to clone, paint, and transform objects along realistic perspective planes automatically. By defining the angles of walls, floors, or surfaces within a scene, the filter dynamically scales, skews, and rotates cloned elements to match the environment's three-dimensional geometry. This guide explains how to set up perspective grids, select clone sources, and duplicate elements seamlessly across complex angles.

Prepare Your Image for Non-Destructive Editing

Before opening the filter, prepare your workspace to ensure your original artwork remains intact. Duplicate your background image layer, or create a new blank layer directly above it. When using a blank layer, ensure the Vanishing Point filter targets the empty layer so all perspective edits are stored independently, allowing for easy masking and opacity adjustments later.

Define the Perspective Grid

  1. Select your working layer and navigate to Filter > Vanishing Point.
  2. Select the Create Plane Tool (keyboard shortcut C) from the toolbar on the left.
  3. Click four corner points on your image that clearly define a flat surface in perspective, such as a tiled floor, brick wall, or window frame.
  4. Observe the grid color: a blue grid indicates a valid, mathematically sound perspective plane, while red or yellow indicates the angles do not represent an accurate perspective and need adjustment. Drag the corner nodes until the grid turns blue.
  5. If cloning onto adjacent surfaces (like a connected wall), hold Ctrl (Windows) or Cmd (Mac) and drag an edge node to create a continuous, perpendicular perspective plane.

Clone Elements Across the Plane

  1. Select the Stamp Tool (shortcut S) from the Vanishing Point toolbar.
  2. In the top options bar, adjust the brush diameter, hardness, and opacity to suit the subject matter.
  3. Choose a Heal mode:
    • Off: Direct clone with no color or brightness blending.
    • Luminance: Retains destination lighting while applying source textures.
    • On: Blends both color and luminance into the destination area for seamless edges.
  4. Set your sample point by holding Alt (Windows) or Option (Mac) and clicking the element you want to duplicate.
  5. Move the cursor to the target area on the grid. Notice how the sampled image preview automatically shrinks or expands to match the exact scale and angle of that specific location on the plane.
  6. Click and drag to paint the cloned pixels into place.

Finalize the Edit

Review the cloned area for alignment errors or repetitive patterns. Once satisfied, click OK in the upper-right corner of the dialog box to render the perspective edits back onto your main document canvas. Use standard layer masks or adjustment layers to fine-tune final blending.
