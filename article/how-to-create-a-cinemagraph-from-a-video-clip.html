How to Create a Cinemagraph from a Video Clip

A cinemagraph is a compelling visual medium that blends a still photograph with a subtle, endlessly looping video element. Creating one requires importing high-definition video footage into an image editor, isolating a single frame to serve as a frozen base, applying a layer mask to reveal movement in a specific area, and blending the timeline to achieve an undetectable loop. This guide breaks down the essential steps to transform raw video into a polished cinemagraph using standard timeline-enabled image editing software like Adobe Photoshop.

Step 1: Choose and Import the Footage

Select a video clip captured on a tripod or stable surface. Camera shake ruins the illusion, so the camera must be completely stationary. In your image editor, open the video file or import it via the video layers feature. This automatically opens the timeline panel, displaying your video on an editable track.

Step 2: Trim the Video Clip

A successful cinemagraph requires only a brief segment of motion, typically between two to four seconds. In the timeline panel, drag the start and end handles of the video layer to isolate the smoothest portion of the movement, such as running water, blinking eyes, or blowing hair.

Step 3: Create the Static Base

Duplicate a single frame from the video to serve as the still image layer.

  1. Move the timeline playhead to a frame where the rest of the composition looks sharp and visually pleasing.
  2. Duplicate the video layer or create a merged copy of the frame on top of your video layer stack.
  3. Rasterize this layer so it behaves as a static image throughout the entire duration of the timeline.

Step 4: Mask the Area of Motion

Add a layer mask to the static top layer.

  1. Select the static layer and click the Add Layer Mask icon.
  2. Select a soft-edged brush tool and set the foreground color to black.
  3. Paint directly on the mask over the exact region where you want motion to occur.

Painting with black creates transparency in the still image, revealing the moving video layer beneath it while keeping the remainder of the scene completely frozen.

Step 5: Build a Seamless Loop

If the motion does not loop naturally, you must create a crossfade to hide the seam where the video restarts:

  1. Split the underlying video layer directly in half.
  2. Move the second half of the clip so it plays first, and place the first half after it.
  3. Overlap the two segments slightly on the timeline.
  4. Apply an opacity transition or crossfade between the overlapping sections so the end seamlessly blends into the beginning.

Step 6: Export the Cinemagraph

Once the preview loops without a noticeable stutter, export your project. For web use with a smaller file size, use the Export for Web option and save it as an animated GIF with looping set to Forever. Alternatively, render the project as an H.264 (MP4) video for higher color fidelity and smooth playback on social media platforms.
