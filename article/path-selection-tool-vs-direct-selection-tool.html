Path Selection Tool vs Direct Selection Tool

Understanding the difference between the Path Selection Tool and the Direct Selection Tool is essential for mastering vector editing in software like Adobe Photoshop and Illustrator. While both tools interact with vector paths and shapes, they operate at different levels of precision. The Path Selection Tool manages entire vector objects as unified components, whereas the Direct Selection Tool targets individual anchor points and path segments to reshape objects with precision.

The Path Selection Tool

The Path Selection Tool, often called the "black arrow," treats a vector path or shape as a single, cohesive unit. When you click anywhere on a path or inside a filled vector shape with this tool, it activates all anchor points simultaneously.

Use the Path Selection Tool to:

  • Move Entire Paths: Click and drag anywhere on a path or shape to reposition the complete object across your canvas.
  • Select Multiple Paths: Drag a marquee around multiple separate paths, or hold the Shift key while clicking, to group and move several vector components at once.
  • Transform Objects: Activate bounding boxes to scale, rotate, or flip a shape without altering its individual curve ratios.
  • Manage Path Operations: Select distinct overlapping paths to apply operations such as Unite, Subtract, Intersect, or Exclude.

The Direct Selection Tool

The Direct Selection Tool, commonly referred to as the "white arrow," provides access to the underlying structure of a vector path. Instead of selecting the whole object, it isolates individual anchor points, curve segments, and direction handles.

Use the Direct Selection Tool to:

  • Move Specific Anchor Points: Click directly on a single anchor point to activate it, then drag it to alter the shape's structure while the remaining points stay locked in place.
  • Modify Curves: Click an anchor point to expose its Bezier handles. Dragging these handles adjusts the angle, depth, and tension of the connected curves.
  • Reshape Segments: Click directly on a line segment between two anchor points to reposition that specific line without directly dragging the points themselves.
  • Delete Sections: Select an individual anchor point or segment and press Delete to open a closed path or remove unwanted vector elements.

Summary of Differences

  • Scope of Control: The Path Selection Tool works at the macro level (the entire object), while the Direct Selection Tool works at the micro level (individual points and lines).
  • Visual Indicators: When using the Path Selection Tool, all anchor points on the path appear filled or solid. When using the Direct Selection Tool, unselected points remain hollow, and only the actively selected point appears solid.
  • Application: Use the Path Selection Tool when arranging, aligning, and organizing components in a layout. Switch to the Direct Selection Tool when drawing custom shapes, refining cutouts, or correcting the curvature of vector masks.
